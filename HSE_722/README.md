## Course description

Develops the use of graphics for both discovering patterns and communicating statistical results. Work uses R graphics and Shiny, with biomedical or health datasets where available. The course links graphical choices to the analytical question and intended audience.

Summary paraphrased from the [course catalog](https://dartmouth.smartcatalogiq.com/en/current/orc/departments-programs-graduate/masters-of-health-science-education/master-of-science-in-health-data-science-online/health-data-science-online/hse-722); checked September 25, 2026.
