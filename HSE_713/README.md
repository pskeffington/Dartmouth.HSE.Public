## Course description

Examines ethical questions raised by AI in biomedical work. Students consider how existing policies and ethical guidance apply to particular uses of AI, identify gaps, and develop questions for evaluating responsible practice. The catalog describes a written analysis proposing improvements in a selected application.

Summary paraphrased from the [course catalog](https://dartmouth.smartcatalogiq.com/en/current/orc/departments-programs-graduate/masters-of-health-science-education/master-of-science-in-health-data-science-online/health-data-science-online/hse-713); checked September 25, 2026. The curriculum uses the broader title “Ethics in Health Data Science” and highlights bias and literature critique.

## Key topics

- Biomedical uses of AI
- Ethical evaluation of application-specific risks
- Critical assessment of policies and guidance
- Development of an argued written position
