# Dartmouth HSE — Public Learning and Research Repository

Public educational coursework, reproducible R helpers, and curated methodological literature. **Not an official Dartmouth course site.** No identifiable patient data, restricted assignments, or private research outputs belong here.

## Six primary sections

| Folder | Purpose |
| --- | --- |
| [Capstone](Capstone/) | Capstone planning, proposals, milestones and final synthesis |
| [Lecture Notes](Lecture%20Notes/) | Course lecture notes and learning-objective commentary |
| [Group Work](Group%20Work/) | Collaborative exercises and reproducible group walkthroughs |
| [Final Project](Final%20Project/) | Final-project deliverables, figures and explanatory work |
| [Assignments](Assignments/) | Individual assignments and reproducible exercise writeups |
| [RESOURCES](RESOURCES/) | R function libraries, plotting utilities, verification tests, curated literature and user guide |

Course IDs appear in filenames or document metadata, not top-level folders. Existing HSE 711 working materials were reorganized by **artifact purpose**. Placeholder-only course directories were removed rather than reproduced.

Start with [RESOURCES/README.md](RESOURCES/README.md) to load the function library and understand the literature evidence categories. Source the statistical helpers before gene visualizations. Tests and examples use synthetic or public data.

## Reproducibility and academic boundaries

Materials are explanatory, not official class documents or clinical software. Gene-expression examples distinguish TMM-normalized CPM/logCPM visualization from count-based statistical inference. See each module for assumptions, code examples and dependencies. Preserve instructor policies on group work, attribution, and use of AI assistance.
