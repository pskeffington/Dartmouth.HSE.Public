## Course description

Brings the program's methods together in an intensive, independently driven health data science project. The capstone emphasizes developing a research problem, carrying out the work, and communicating the findings. It provides an opportunity to integrate analytical and professional skills.

Summary paraphrased from the [course catalog](https://dartmouth.smartcatalogiq.com/en/current/orc/departments-programs-graduate/masters-of-health-science-education/master-of-science-in-health-data-science-online/health-data-science-online/hse-771); checked September 25, 2026.
