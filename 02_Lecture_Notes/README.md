# Lecture Notes

Narrative teaching companions for **HSE 711: Foundations in Data Science**. Each document explains the motivation for a method, how the code operates and what can reasonably be concluded. These are independent study notes, not official lecture handouts.

## Available lessons

| Week | Topic | Material |
| --- | --- | --- |
| 2 | Data wrangling and visualization | [Learning objective notes (.R)](Week_2_Learning_Objective_Notes.R) |
| 3 | Data visualization and analytics | [Learning objective notes (.R)](Week_3_Learning_Objective_Notes.R) |
| 4 | Introduction to Bash scripting | [Narrative lecture companion (.Rmd)](Week_4_Introduction_to_Bash_Narrative_Walkthrough.Rmd) |

**Reading the files:** `.R` documents contain commented lesson content and runnable code. `.Rmd` files contain scholarly prose and executable Markdown code chunks; they can be read on GitHub or rendered locally using R Markdown and installed dependencies.
