## Course description

Introduces regression as a tool for prediction and causal inquiry in health research. The catalog emphasizes linear regression, including estimation, inference, model checking, covariate selection, and handling missing data. Analyses use R.

Summary paraphrased from the [course catalog](https://dartmouth.smartcatalogiq.com/en/current/orc/departments-programs-graduate/masters-of-health-science-education/master-of-science-in-health-data-science-online/health-data-science-online/hse-731); checked September 25, 2026. The program curriculum also mentions introductory generalized linear models; the catalog emphasizes linear regression. The syllabus determines the term's coverage.

## Key topics

- Fitting and interpreting linear models
- Statistical testing and estimation
- Model diagnostics
- Covariate selection and missing-data considerations
