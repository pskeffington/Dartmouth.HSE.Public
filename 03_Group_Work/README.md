## Choose and finish a week

Start with the complete lesson, use the topic companion for a focused reminder, and finish the lesson's **Ready to move on** table. Keep a script, validation evidence, labeled outputs, and a short explanation. The checkpoints describe the public practice examples and can be used to check your own method on a different dataset.

[Setup and study workflow](../FOLLOW_ALONG.md) covers installations, running scripts, expected evidence, and common errors.
