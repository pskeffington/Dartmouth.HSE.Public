## Course description

Connects molecular understanding with computational analysis of genomic information. The course surveys data science applications in genomics and contemporary research topics, emphasizing the need to interpret biological data in context.

Summary paraphrased from the [course catalog](https://dartmouth.smartcatalogiq.com/en/current/orc/departments-programs-graduate/masters-of-health-science-education/master-of-science-in-health-data-science-online/health-data-science-online/hse-753); checked September 25, 2026.
