## Course description

Introduces the computational and mathematical foundations used throughout health data science. Students work in R to organize, explore, and visualize data while reviewing the mathematics that supports later statistical methods.

Summary paraphrased from the [course catalog](https://dartmouth.smartcatalogiq.com/en/current/orc/departments-programs-graduate/masters-of-health-science-education/master-of-science-in-health-data-science-online/health-data-science-online/hse-711); checked September 25, 2026.

## Key topics

- R-based data manipulation and exploratory analysis
- Graphical presentation of data
- Review of sequences, series, differentiation, and integration
- Introductory exposure to machine learning, LaTeX, Git/GitHub, and high-performance computing

## Place in the program

Provides a practical starting point for biostatistics, data wrangling, and visualization.
