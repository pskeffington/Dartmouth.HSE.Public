## Interpretation map

### Claims currently well-supported by literature + project data

- Breast cancer contains reproducible transcriptional subtypes; PAM50 is a standard intrinsic-subtype framework (LM-001–LM-006).
- Tumor-adjacent normal breast is biologically informative but is not equivalent to disease-free healthy breast; tissue composition and field effects matter (LM-007–LM-010).
- Patient-blocked edgeR quasi-likelihood modeling and rank-based pathway analysis are methodologically appropriate for the project's RNA-seq workflow (LM-011–LM-015).
- FOXC1 as a strong Basal-associated signal and proliferation as a LumB/LumA separator have independent biological precedent (LM-016–LM-017).
- PAM50 state can vary across disease context, supporting specimen-specific rather than immutable-patient interpretation (LM-018).
- GSE173991 and GSE81540 are breast-cancer resources, but they answer different validation questions (LM-019–LM-022).
- GSE165252 is not a breast-cancer validation cohort and should remain excluded from direct external validation (LM-023).

### Claims that remain project-derived and require external validation

- Exact genome-wide paired tumor-normal logFC values.
- The 8,472-gene PAM50 interaction set.
- The six planned pairwise subtype-effect discovery counts.
- The frozen 60-gene compact subtype signature.
- The exact compact pathway set and subtype-specific pathway-effect matrix.
- The proposed use of GSE173991 for any *paired* test until sample pairing is explicitly verified.

## Literature-use rules

1. Do not use a literature row to claim replication of a project result unless the cited study actually tests the same contrast.
2. Keep tumor-adjacent normal distinct from cancer-free healthy breast.
3. Keep PAM50 molecular subtype distinct from IHC surrogate subtype.
4. Keep tumor-expression subtype comparisons distinct from paired tumor-minus-normal subtype-effect comparisons.
5. Treat external cohorts as separate validation streams when their designs differ.
6. Do not redefine the frozen discovery signature after inspecting external-cohort results.
7. Add new papers with a new LM identifier; do not silently overwrite the evidence statement for an existing row.

### Implementation priorities

1. **Preserve model inputs:** hold raw/estimated count semantics, sample-patient pairing, feature identifiers, factor reference levels and normalization factors constant; CPM and log-CPM are descriptive displays, not substitutions for count-based edgeR inference.
2. **Audit EDA:** assess library sizes, effective library sizes, expression detectability, CPM/log-CPM distributions, mean-variance patterns, MDS/PCA, missingness and potential batch/group confounding. Freeze gene selections and contrasts before inferential review.
3. **Pre-run optimization:** invoke existing R18 preflight; reuse frozen/hash-matched assets, profile cold/warm wall time and observed memory, minimize matrix materialization, constrain parallel threads and require numerical/statistical equivalence *before* accepting any speed improvement.
4. **Reproducible functions:** implement idempotent stages with explicit input/output contracts; use small pure functions, `stopifnot`/structured assertions for sample order and uniqueness, package/session manifests, deterministic seeds for stochastic operations, SHA-256 fingerprints and versioned figures/tables.
5. **Independent verification:** verify numerical invariants and existing 240 frozen QL effect checks; do not authorize confidence intervals or external biological replication on the strength of computational equivalence alone.

**Priority order:** P0 data/model validity and provenance; P1 EDA and assay-scale semantics; P2 reproducible code and dependency pinning; P3 measured throughput optimization; P4 optional independent method/assay extensions.

### CPM and inference boundary

From the original counts and a checked edgeR DGEList, estimate TMM factors with `calcNormFactors()`. Calculate normalized CPM and logCPM for abundance review, PCA/MDS and selected-gene plots. Label values explicitly as TMM-adjusted CPM or log2 CPM with the chosen prior count. Design-aware inference filtering uses `filterByExpr(..., design=...)`; a fixed CPM cutoff may separately describe detectability but must not silently replace filtering. Differential-expression models use the underlying counts and offsets, not substituted CPM values.

### Statistical coding and figure-release protocol

1. Use established, explicitly namespaced R/Bioconductor functions; make gene/sample ordering, pairing, identifier uniqueness, factor references and contrasts executable assertions.
2. Reuse validated cached assets. Profile memory allocation and calls before optimization; avoid unnecessary dense conversions and repeated joins. Measure cold and warm runtime and peak memory; accept changes only after checking output equivalence.
3. Separate data transforms from plotting functions and file export. Reusable chart functions should take input table, assay scale, gene panel, strata, figure profile and labels, and return ggplot objects.
4. Figures must give biological group n, meaningful axis units, method labels, consistent ordering, accessible palettes, and legible final-size typography. Use vector PDF/SVG where suitable; raster export at 300 dpi or higher when needed. Confirm facet labels and legends are not clipped.
5. Descriptive gene distributions are not inferential confidence intervals. Do not add significance marks without justified tests; do not modify frozen R11/R18 inference or bypass the mandatory R18 pre-run optimization gate.
6. Log input fingerprints, code commit, package versions, transformation and plotting parameters and figure hashes with each publication candidate.
