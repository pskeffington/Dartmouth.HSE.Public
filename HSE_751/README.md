## Course description

Introduces programming approaches for solving health data science problems. Live examples and exercises use Python and Bash and introduce high-performance computing. The course develops computational practice that can support later analytical workflows.

Summary paraphrased from the [course catalog](https://dartmouth.smartcatalogiq.com/en/current/orc/departments-programs-graduate/masters-of-health-science-education/master-of-science-in-health-data-science-online/health-data-science-online/hse-751); checked September 25, 2026.
