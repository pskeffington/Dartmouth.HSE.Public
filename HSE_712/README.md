## Course description

Develops the statistical reasoning needed to interpret health data and quantify uncertainty. The course connects probability models and sampling behavior to estimation and hypothesis testing, with analyses implemented in R.

Summary paraphrased from the [course catalog](https://dartmouth.smartcatalogiq.com/en/current/orc/departments-programs-graduate/masters-of-health-science-education/master-of-science-in-health-data-science-online/health-data-science-online/hse-712); checked September 25, 2026.

## Key topics

- Random variables and probability distributions
- Sampling distributions and the central limit theorem
- Confidence intervals and interpretation of p-values
- Parametric, nonparametric, and categorical-data methods

## Place in the program

Provides the inferential foundation for the regression sequence and for interpreting results in later projects.

Program connections above are a repository interpretation, not additional enrollment requirements.
