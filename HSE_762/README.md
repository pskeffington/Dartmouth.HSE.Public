## Course description

Focuses on constructing applications that use AI models, especially generative models and large language models. Students examine how models are integrated into pipelines with retrieval, supporting data stores, tool interactions, and processing around model calls.

Summary paraphrased from the [course catalog](https://dartmouth.smartcatalogiq.com/en/current/orc/departments-programs-graduate/masters-of-health-science-education/master-of-science-in-health-data-science-online/health-data-science-online/hse-762); checked September 25, 2026.

## Key topics

- Generative AI and large language models
- Input and output processing
- Retrieval-augmented generation and vector stores
- Tool use and agent behavior
