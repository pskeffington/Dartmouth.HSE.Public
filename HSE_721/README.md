## Course description

Focuses on restructuring data so it can support subsequent analysis. Students examine data representations and practice operations that create, combine, select, and transform datasets. The emphasis is on understanding how the organization of data affects analytical work.

Summary paraphrased from the [course catalog](https://dartmouth.smartcatalogiq.com/en/current/orc/departments-programs-graduate/masters-of-health-science-education/master-of-science-in-health-data-science-online/health-data-science-online/hse-721); checked September 25, 2026.

## Key topics

- Data structures and file representations
- Creating and combining datasets
- Selecting relevant observations and variables
- Transforming structures for downstream analysis
