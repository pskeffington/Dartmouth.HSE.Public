# Group Work

Worked group exercises and narrative walkthroughs. Check each document for assumptions and reproducibility instructions.

## Interpreting numerical exercises

When a walkthrough asks for descriptive statistics, summarize valid observations and missingness separately. Report the mean and SD together, and the median alongside Q1, Q3 and IQR for distributional context. The public [summary guide](../RESOURCES/SUMMARY_STATISTICS.md) includes reusable R calls and automatically generated narrative interpretation. It does not replace an assignment's original instructions.
